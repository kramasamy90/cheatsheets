\subsection{Fundamentals}


\subsubsection{Pre-processor}

\begin{minipage}{\linewidth}
Pre-processor directive always start with a '\texttt{\#}'.

\begin{itemize}
    \item \texttt{\#include \textit{filename}}\\

    \item \texttt{\#define NAME \textit{replacement text}} \\
    \texttt{NAME} is replaced with \texttt{\textit{replacement text}} \\

    \item \texttt{\#define \textit{token}(arg1,arg2) \textit{statement}} \\
    Defining a macro. Eg: \\
    \texttt{\#define max(A,B) ((A) > (B) ? (A) : (B))}

    \item \texttt{\#undef NAME} \\
    Nullifies existing definition of \texttt{NAME}. 

    \item \texttt{\#if}, \texttt{\#elif},\texttt{\#else}, \texttt{\#endif}\\

    \item \texttt{\#ifdef}  and \texttt{\#ifndef}\\
    Used in header-guards. Eg: \\
    \begin{verbatim}
        #ifndef HEADER_FILE_NAME
        #define HEADER_FILE_NAME
        ...
        #endif
    \end{verbatim}

    \item \texttt{\#pragma once}: Single-inclusion header guard.\\
            Widely supported, but not guaranteed.
    \item \texttt{\#error "message"}: Emit a compile-time error.
    \item \texttt{\#warning "message"}: Emit a compile-time warning (compiler extension).
    \item \texttt{\#line N "file"}: Change reported line/file in diagnostics.
    \item Built-ins: \verb|__FILE__|, \verb|__LINE__|, \verb|__DATE__|, \verb|__TIME__|, \verb|__cplusplus(C++ version)|.

\end{itemize}
\end{minipage}
